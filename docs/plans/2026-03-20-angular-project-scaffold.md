# FRONT-001: Angular Project Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the Angular 21 project skeleton in `frontend/`, configure the build pipeline, and wire FastAPI to serve the built SPA alongside existing HTMX pages.

**Architecture:** Angular CLI generates a standalone-component project in `frontend/`. A dev proxy forwards `/api/v3` and `/stream` requests to FastAPI at port 5000. In production, FastAPI uses a single catch-all route that serves static files (JS, CSS) from the SPA dist directory and falls back to `index.html` for Angular client-side routing. This avoids `StaticFiles` mount conflicts. Existing HTMX pages at `/v3/`, static files at `/static/`, API at `/api/v3/`, and docs at `/docs`/`/redoc` are all preserved.

**Tech Stack:** Angular 21 (standalone components, SCSS), FastAPI, Node.js 18+, npm

**Sprint ticket:** `sprints/v3.0.0/FRONT-001-angular-project-scaffold.md`

## Task 7: Implement FastAPI SPA Mount (GREEN)

**Files:**
- Modify: `src/api/main.py:26-97`

Implement the minimum code to make the RED tests pass.

- [ ] **Step 1: Add SPA mount logic to create_app()**

In `src/api/main.py`, add new imports at the top:

```python
from fastapi.responses import HTMLResponse
from starlette.responses import FileResponse
import mimetypes
```

At the end of `create_app()`, BEFORE `return app`, add the SPA catch-all route. This must come AFTER all other routes and mounts. The SPA dist path is computed inside `create_app()` (not module-level) so it can be patched in tests via `PROJECT_ROOT`:

```python
    # Mount Angular SPA (when built) — single catch-all serves both
    # static assets and index.html fallback for client-side routing.
    # Computed inside create_app() so PROJECT_ROOT can be patched in tests.
    spa_dist_dir = PROJECT_ROOT / "frontend" / "dist" / "ledmatrix" / "browser"
    if spa_dist_dir.is_dir():
        _SPA_RESERVED_PREFIXES = (
            "/api/", "/docs", "/redoc", "/static", "/v3",
            "/openapi.json", "/favicon.ico",
        )

        @app.get("/{full_path:path}", include_in_schema=False)
        async def spa_catch_all(full_path: str) -> Response:
            """Serve SPA static files or index.html for client-side routing."""
            request_path = f"/{full_path}"
            for prefix in _SPA_RESERVED_PREFIXES:
                if request_path.startswith(prefix):
                    return Response(status_code=404)

            # Serve static file if it exists (JS, CSS, images, etc.)
            if full_path and ".." not in full_path:
                file_path = spa_dist_dir / full_path
                if file_path.is_file():
                    media_type = mimetypes.guess_type(str(file_path))[0]
                    return FileResponse(file_path, media_type=media_type)

            # Fall back to index.html for Angular client-side routing
            index_file = spa_dist_dir / "index.html"
            if index_file.is_file():
                return HTMLResponse(content=index_file.read_text())
            return Response(status_code=404)
```

**Key design decisions:**
- No `app.mount("/", StaticFiles(...))` — avoids mount/route precedence conflicts
- `spa_dist_dir` computed inside function, not module-level — testable via `PROJECT_ROOT` patch
- `".." not in full_path` — prevents path traversal
- `FileResponse` with MIME type detection — proper content-type for JS/CSS/images
